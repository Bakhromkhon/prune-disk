Обзор отчёта

Просмотрщик: не сканирует компьютер и не удаляет файлы.

Файл .json до 5 МиБ · обрабатывается только в вашем браузере, никуда не отправляется.

Где взять отчёт?

Экспорт пока технический: Prune — alpha, простого экспорта через интерфейс ещё нет. Если CLI уже установлен, выполните в терминале:

prune scan --json > report.json

Затем откройте report.json здесь. Команда сканирует, но не удаляет файлы. Отчёт может содержать личные пути — не публикуйте его без проверки.
