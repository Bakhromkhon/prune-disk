# Prune · локальный preview

Автономный просмотрщик JSON-отчётов, не Tauri GUI и не готовое desktop-приложение. Не сканирует диск, не удаляет файлы и не запускает команды.

## Открыть

Откройте `preview/index.html` в браузере. Классические внешние скрипты позволяют работать через `file://`, без модулей и запросов за демо-данными.

Если браузер ограничивает локальные ресурсы, запустите из корня проекта:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory preview
```

Откройте `http://127.0.0.1:8080`. Это статический сервер, без API записи. Зависимости, установка пакетов и сеть не нужны.

## Использование и конфиденциальность

- При открытии показан **вымышленный** отчёт: все пути начинаются с `/example`, данные не получены с реальной машины.
- «Открыть отчёт…» читает выбранный файл через `FileReader` только в памяти браузера. Никаких сетевых запросов, localStorage, cookies, аналитики, внешних шрифтов или CDN. «Посмотреть пример» возвращает вымышленные данные. После перезагрузки снова показывается пример.
- В раскрываемой подсказке «Где взять отчёт?» приведена команда `prune scan --json > report.json`. Нужен установленный CLI: Prune — техническая alpha, простого экспорта через интерфейс пока нет. Viewer не выполняет эту команду.
- Источник явно помечен как «Пример — не данные компьютера» или «Открытый файл». Версия схемы находится в диагностике.
- Ищите по названию/пути/описанию, фильтруйте категории и риск удаления, сортируйте. Сброс фильтров возвращает список и фокусирует поиск. Отдельно объясняются пустой полный отчёт, пустой неполный отчёт и отсутствие совпадений с фильтрами.
- Название строки выбирает расположение без переноса фокуса. «Перейти к подробностям» над списком и у каждой строки фокусирует заголовок панели; «Обратно к списку» возвращает фокус к кнопке перехода. По 30 строк на страницу; подробности всегда относятся к текущей странице. Номер страницы объявляется полностью; при достижении края фокус переходит с отключившейся кнопки на номер страницы.
- Ошибки импорта дают следующее действие и отдельную раскрываемую техническую причину; предыдущий отчёт остаётся доступным. Live region очищается и заполняется через два кадра, в том числе при повторении той же ошибки. Более старые чтения и объявления не заменяют результат нового выбора файла.
- Отчёт содержит потенциально чувствительные пути: не публикуйте JSON или скриншоты без проверки. Расширения браузера и сам браузер не находятся под контролем viewer.

Поддерживается `ScanReport` со `schema_version: 1`. Предел файла — 5 МиБ; максимум 10 000 findings и 1 000 errors. Неизвестные категории, риск и восстановление отклоняются. Числа должны быть неотрицательными безопасными целыми JS, строки ограничены 8 192 UTF-16 кодовыми единицами (platform — 128). Итоги должны совпадать с находками; необязательные флаги старых отчётов имеют значения по умолчанию Rust-модели. Неизвестные дополнительные поля игнорируются и не отображаются. Поле `last_modified` обязательно, допускается `null`.

`cancelled`, ошибки, `suppressed_errors` или неполные находки всегда означают неполный отчёт, даже если исходный `partial` равен false. Все ошибки и число подавленных ошибок доступны в раскрываемой диагностике. Логический размер — не прогноз освобождения места; жёсткие ссылки могут учитываться повторно.

«Минимальный» риск означает минимальный **по оценке правила**, не отсутствие риска и не разрешение на удаление; пояснение постоянно видно над фильтрами. «Как данные могут появиться снова» описывает механизм повторного создания, а не гарантирует восстановление удалённых файлов. Суммарный размер файлов не равен освобождаемому месту.

Данные отображаются через `textContent`; управляющие символы C0/C1, bidi и обратные слеши экранируются для видимости. Пути не превращаются в ссылки и не открываются. CSP запрещает сеть, формы, inline-скрипты и сторонние ресурсы. Это защитные ограничения viewer, а не универсальный антивирус или проверка происхождения отчёта.

## Визуальная система

Сохранены тёплый светлый фон и emerald-акцент. CSS развёрнут для сопровождения: основной текст и контролы — 14 px, метаданные — не меньше 12 px, интерактивные контролы — не меньше 44 px по высоте. Отступы панелей и межсекционные интервалы используют `--space`: 24 px, на ширине до 700 px — 16 px. До 1100 px список и подробности расположены друг под другом; на мобильном категории идут в одну колонку. Широкая таблица прокручивается внутри своего контейнера, не документ.

Проверенные пары контраста по формуле относительной яркости sRGB:

| Назначение | Текст / фон | Контраст |
| --- | --- | --- |
| Placeholder и вторичный текст | `#52615b` / `#ffffff` | 6,52:1 |
| Счётчик | `#52615b` / `#eff2ee` | 5,78:1 |
| Граница поля / белое поле | `#7a887f` / `#ffffff` | 3,71:1 |
| Граница поля / фон страницы | `#7a887f` / `#f7f8f5` | 3,48:1 |
| Основная кнопка | `#ffffff` / `#13765c` | 5,56:1 |

Категории идут по убыванию размера; проценты и доступные `meter` используют один знаменатель — суммарный размер отчёта. Нулевой размер отображается как 0%, без деления на ноль.

## Проверки

```sh
node --test preview/*.test.mjs
node --check preview/app.js
node --check preview/report.js
```

`report.js` — общая библиотека классического браузерного скрипта; `report.mjs` — ES-module оболочка для встроенного Node test runner. `demo-report.json` соответствует встроенному в `app.js` демо.

`app.test.mjs` выполняет настоящий `app.js` в минимальном DOM-адаптере Node: проверяет выбор при пагинации, фильтры, пустые состояния, порядок и общий знаменатель категорий, явные переходы фокуса, семантику объявлений, ошибки и гонки импорта, повторение ошибки и текстовое отображение недоверенных данных. `styles.test.mjs` проверяет численный контраст, минимальные размеры и наличие адаптивных правил. `report.test.mjs` сохраняет проверки валидатора и лимитов.

DOM-адаптер не моделирует раскладку, реальное поведение screen reader или нативный диалог выбора файлов. Эти тесты не означают полную проверку WCAG или пиксельную проверку интерфейса. Для ручной проверки используйте отдельную вкладку: 375 px, 700 px, 900 px, 1100 px и desktop; пройдите Tab/Enter к подробностям и обратно, проверьте отсутствие горизонтальной прокрутки документа, повторный ошибочный импорт и объявления с screen reader.
